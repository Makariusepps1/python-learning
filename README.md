# python-learning

Hands-on Python practice — learning by building, one small program at a time.

## So far
- **Lesson1_protein.py** — variables, lists, dictionaries, functions, and loops.
  A mini protein tracker: logs meals, totals protein against a daily goal,
  and reports what's left.

- **lesson2_loops.py** — for loops, an accumulator, if statements, and .append().
  The meal tracker grows to four meals and tags the high-protein ones.

Everything here is typed and debugged by hand, so I can explain every line.
